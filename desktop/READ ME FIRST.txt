ASTRONOMER-LITE
Mac installation and first launch

INSTALL

1. Drag Astronomer-Lite.app to Applications. In the disk image, you can use
   the Applications shortcut beside the app. For a ZIP download, move the
   extracted app into your Applications folder.
2. Open Astronomer-Lite from Applications.

IF APPLE BLOCKS THE FIRST LAUNCH

Unsigned release candidates have not been notarized by Apple. For these
builds, macOS may say that Apple cannot check Astronomer-Lite for malicious
software, or that the developer cannot be verified.

For a copy you downloaded from our official GitHub release:

1. Dismiss the warning with Done or Cancel, leaving the app in Applications.
2. Go to the Apple menu and open System Settings.
3. Select Privacy & Security, then scroll to the Security section.
4. Find the message about Astronomer-Lite and choose Open Anyway.
5. Authenticate if requested, then choose Open in the confirmation dialog.

macOS saves an exception for this app. You can then launch it normally
from Applications.

If Open Anyway is missing, try launching the installed app once more and
return to Privacy & Security. On a managed Mac, your administrator may
restrict this option.

These instructions apply to the unverified-developer/notarization warning.
If macOS reports detected malware or a damaged app, stop and contact us.
