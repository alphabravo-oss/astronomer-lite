# Astronomer-lite Verification Checklist

This checklist maps the project objective to concrete artifacts and the current verification state.

## Objective

Build a Vite + React + Tailwind, single-container Kubernetes UI that visually follows `../astronomer/frontend`, behaves like a local Headlamp-style kubeconfig tool, and lets users manage remote clusters by loading kubeconfigs.

| Requirement | Evidence |

## Pending External Gate

The full k3d suite has not been observed green on this machine because `k3d` is not installed here and the user deferred Linux-node testing.

Run this on a Linux node with Docker, k3d, kubectl, Node, and Go:

```bash
make k3d-e2e
```

That command creates a real k3d cluster, injects a fake unreachable kubeconfig context, starts `astronomer-lite`, and runs `web/e2e/k3d.spec.ts`.
Use `KEEP_K3D_CLUSTER=1` and `KEEP_E2E_CONFIG_DIR=1` when debugging failures; see `README.md` for the full runner environment variable table.

## Completion Rule

Do not mark the implementation complete until `make k3d-e2e` is observed green, or the project explicitly accepts Linux/k3d verification as deferred outside the completion criteria.
