# Astronomer-Lite 0.2.0-rc.1

Release candidate for the single-instance Kubernetes workspace, with Astronomer
UI styling and Astronomer-Lite branding. Licensed under Apache-2.0.

- Local desktop and single-container deployment, with isolated server-mode users,
  local login, OIDC, MFA, and encrypted per-user cluster credentials.
- Cluster resource editing, YAML validation, logs, exec, port forwarding, Helm
  workflows, topology, metrics, and reusable resource tables and dialogs.
- Native installers targeted at macOS Intel/Apple Silicon, Windows x64, and
  Linux x64, including RPM compatibility checks for RHEL 8, 9, and 10.
- External plugins remain disabled by default and deferred from the 0.2.0 UI.
- Shared styling and reusable controls, with unused navigation and UI code removed.

This is a release candidate. Production signing/notarization is deferred;
unsigned installers are accepted for this release path. Hosted Mac/Windows/Linux installer tests and UBI 8/9/10 checks gate the
prerelease draft. Windows 11 workstation and graphical RHEL 8/9/10 validation
remain pending and are required before a stable desktop release. Artifact availability alone
does not establish native validation. Multi-replica HA is outside this release.
See docs/releasing.md for release gates and remaining operator setup.
