# Astronomer-Lite 0.2.0-rc.2

Mac installation guidance for the unsigned Astronomer-Lite release candidate.

- Both Intel and Apple Silicon DMGs now show `READ ME FIRST.txt` alongside
  Astronomer-Lite.app and the Applications shortcut.
- The same instructions appear beside the app when either Mac ZIP is extracted.
- The guide explains installation and the macOS **System Settings → Privacy &
  Security → Open Anyway** steps, with a link to Apple's instructions.
- Native Mac packaging checks verify that both the mounted DMG and ZIP contain
  the exact instructions before testing the installed application.

This is a packaging/documentation update to 0.2.0-rc.1. Application functionality
is unchanged. Plugins remain disabled by default. Licensed under Apache-2.0.

Production signing and Apple notarization remain deferred. The Mac apps have
ad-hoc local signatures, which do not establish a trusted publisher. The guide
helps users approve the current build; it does not remove the macOS warning.

Hosted Mac/Windows/Linux installer tests and UBI 8/9/10 runtime checks gate this
prerelease. Windows 11 workstation and graphical RHEL 8/9/10 validation remain
pending and are required before a stable desktop release.
