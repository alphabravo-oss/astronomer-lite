# Astronomer Lite 0.2.0-rc.3

This candidate updates Astronomer UI alignment, navigation, accessibility and desktop branding. Plugins remain disabled by default; operation remains single-instance with file-backed state.

- Use **Astronomer Lite** consistently in the UI, application menus, window titles and installed app names. Existing desktop profiles keep their original storage location.
- Add native **Settings…** under the app menu on macOS and File on Windows/Linux, with Command/Ctrl-comma. Settings navigation preserves the current workspace without a page reload.
- Match Astronomer's collapsed sidebar: one icon per resource group, labeled flyouts, a top expand/collapse control and accessible cluster/pinned links.
- Share density-aware cards, keyboard-accessible tabs, modal drawers, table controls and global semantic colors. Improve short-window/mobile dialogs, long cluster cards, error wrapping and command-palette scrolling. All HTML tables use the shared global table styles; main inventory tables retain saved column controls.
- Align reading-page widths and full-width resource/tool views. Load heavy routes on demand, approximately halving the initial JavaScript bundle. Add recovery pages for unknown routes and failed route loads.
- Preserve the Mac first-launch guide alongside the app in DMG and ZIP packages.

Packages cover Linux x64 (AppImage/DEB/RPM), Windows x64, and macOS Intel/Apple Silicon (DMG/ZIP). Download filenames retain `Astronomer-Lite` for release-tool compatibility; installed display names use **Astronomer Lite**.

This is an unsigned release candidate. Production signing/notarization is deferred. Windows 11 and graphical RHEL 8/9/10 workstation validation remain pending; UBI runtime checks are not graphical desktop certification. Production cloud-helper/IdP configurations and large-fleet behavior still require environment-specific validation. See the bundled Mac guide for Apple's **Open Anyway** procedure.
